PerplexPDF 1.0.0 | Windows 11 x64

Extract the entire ZIP to a folder you can write to. Run PerplexPDF.exe
from that folder. Keep the other files and directories beside the EXE.

To install for your user, run Setup-PerplexPDF.cmd from the extracted folder.
Choose PerplexPDF for .pdf in Windows Settings > Apps > Default apps.

Open example.pdf to try the viewer and the Edit text toolbar button.
Export to Word defaults to Editable text, with pictures, graphics and color.
Try both Word modes with examples/word-layout.pdf. See USER_GUIDE_EN.md for details.

LICENSE contains the MIT license for PerplexPDF. Read
THIRD_PARTY_NOTICES.txt and licenses/ for bundled components.
Use Save Project (.ppdf) to preserve editable objects and Save PDF As
to create an exchange copy. Exported overlays are page content.
