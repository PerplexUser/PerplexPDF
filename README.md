PerplexPDF is a desktop PDF editor that runs locally on Windows, Linux, and macOS.
Edit existing text, annotate and rearrange pages, add signature images, and make scans searchable with offline OCR.
Export PDFs as editable Word documents that retain images and colors, or create EPUB books with embedded images and a navigable table of contents.

Installation files: https://github.com/PerplexUser/PerplexPDF/releases/tag/v1.1.0
