This directory accompanies the local Windows OCR test assembled from the
project owner's supplied, unchanged Tesseract 5.5.3 installer files.

Tesseract source and release:
https://github.com/tesseract-ocr/tesseract/releases/tag/5.5.3
The original Tesseract LICENSE and AUTHORS are extracted byte for byte.
English and German model source:
https://github.com/tesseract-ocr/tessdata_fast/tree/4.1.0

The installer workflow draws dependency DLLs from MSYS2 mingw64 and MinGW.
See the pinned installer and payload SHA-256 values in tesseract-local-test.lock.json.
The retained import chain includes libtiff and JBIG-KIT 2.1 under the GPL.

for local review. Public redistribution requires a review of the exact
